# ASR Studio extension icons

These PNGs render the existing symbol-only favicon from
`src/asr_studio/web/shell.html`: the ASR Studio waveform and studio fader,
burgundy on warm paper. They contain no wordmark. The transparent rounded
corners and opaque paper background preserve contrast on browser toolbars.

The PNGs were promoted from the pinned client source. Keep the symbol-only
files and these license notices together when preparing an internal bundle.
